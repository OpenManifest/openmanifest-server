# Bug register (both repositories)

Single register for `OpenManifest/openmanifest-server` (repo = **backend**) and `OpenManifest/openmanifest`
(repo = **client**). Created in modernisation pass 1 (2026-10-08) at backend `b8dc33a` / client `3112795`.

Rules for executors:

- New bugs found while working a task are **appended** here with the next free ID; do not fix them out of scope.
- When a task fixes a bug, the task's PR changes the bug's row: prefix the Description with `FIXED in P{x}.{y}:`.
- Every row is either referenced by a task's `Fixes:` line in [`../MODERNISATION_PLAN.md`](../MODERNISATION_PLAN.md) or
  listed in the plan's "Deferred bugs" table with a reason.

Confidence: **confirmed** = reproduced in pass 1 (throwaway spec, rails runner, dev server, web build) or the code
unambiguously exhibits it; **likely** = clear from code but not executed; **suspected** = plausible risk not verified.
"Audit spec" means a throwaway RSpec file run against the test DB in pass 1 (not committed); its outputs are quoted.

## Android / mobile layout: shared root causes

Device behaviour could not be run in the VM (no emulator). Findings come from static analysis plus a web export viewed
in headless Chromium at 360×640 and 1280×800. They group into these root causes; Phase 5 fixes the root causes first.

| Root cause | Bugs | Where it bites |
|---|---|---|
| RC1 fixed widths/min-widths ≥ 300–400 dp on a 360–411 dp wide phone | BUG-070 | every wizard (sign-up, user setup, dropzone setup, password flows), weather form, login landscape, compact load cards |
| RC2 no safe-area handling; hard-coded bottom offsets | BUG-071 | headerless screens (login, wizards, limbo), FAB groups, bottom sheets. Gets worse on Expo SDK ≥ 54 where Android is edge-to-edge |
| RC3 heights computed from window size | BUG-072 | manifest board, card view, `ScrollableScreen`, `WizardScreen` |
| RC4 keyboard handling (KeyboardAvoidingView `behavior` undefined on Android, bottom-sheet padding hack, plain `TextInput` in sheets) | BUG-073 | wizards (GitHub issues client#133, #134), manifest/credits/aircraft sheets |
| RC5 vertical `FlatList` nested in `ScrollView` | BUG-074 | load screen slot table, dropzones table |
| RC6 FAB rendered inside scroll content | BUG-075 | aircraft, ticket types, dropzone rigs screens |
| RC7 non-scrollable root on a tall form | BUG-076 | login screen (Sign up button off-screen at 360×640, reproduced on web) |
| RC8 fixed-height text rows / very large fonts vs Android font scale | BUG-077 | slot table rows, aircraft rows, wizard titles (72 pt), jump run text (50–60 pt) |
| RC9 platform style branches that omit Android | BUG-078 | weather condition text fields |
